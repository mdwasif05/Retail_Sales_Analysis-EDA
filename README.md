# Retail Sales Analysis - EDA Project

## 📊 Project Overview
Analyzed 1000+ retail transactions to uncover sales trends, customer behavior, and product performance. This is an end-to-end Exploratory Data Analysis (EDA) project using Python & Jupyter Notebook.

## 📁 Dataset
- **Source:** Retail Sales Dataset (1000 Transactions, 2023-2024)
- **Columns:** Transaction ID, Date, Customer ID, Gender, Age, Product Category, Quantity, Price per Unit, Total Amount

## 🛠️ Tech Stack
- Python, Pandas, NumPy
- Matplotlib, Seaborn
- Jupyter Notebook

## 🔍 Key Analysis Performed
1. Data Cleaning & Type Conversion
2. Sales Trend Analysis (Monthly)
3. Product Category Performance
4. Customer Demographics (Age, Gender)
5. Average Order Value (AOV)
6. Regional/Product Insights

## 📈 Key Business Insights
- **Peak Sales:** November-January (Festive Season)
- **Top Category:** Electronics contributes ~40% revenue
- **Customer Segment:** 26-35 age group spends the most
- **Gender Trend:** Females dominate Beauty, Males dominate Electronics
- **Average Order Value (AOV):** ₹457.12 (from analysis)
